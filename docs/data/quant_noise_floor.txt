Reading: two honest Q4 quantisations of the same weights differ by up to ~0.95 in raw logits and ~0.1-0.17 on
average. An engine matching llama.cpp on the SAME file should sit far below this (same weights, same math up to
accumulation order); parity against llama.cpp on the same GGUF is the Phase 3 gate, and the bf16 distance is
what this file will hold once the shards are approved.
