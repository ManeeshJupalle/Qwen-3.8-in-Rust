## Derived: layer schedule

- `text_config.layer_types` has 64 entries; distinct values: ['full_attention', 'linear_attention']
- full_attention layer indices (**0-based**, index into `layer_types`): `[3, 7, 11, 15, 19, 23, 27, 31, 35, 39, 43, 47, 51, 55, 59, 63]`
- count: 16 full_attention, 48 linear_attention
- rule check: `(i+1) % full_attention_interval == 0` gives `[3, 7, 11, 15, 19, 23, 27, 31, 35, 39, 43, 47, 51, 55, 59, 63]`; matches layer_types: **True**
- so with 0-based indexing the full-attention layers are 3, 7, 11, ... 63 (every 4th, the LAST of each group of 4),
  NOT 0, 4, 8, ... The engine must read `layer_types`, not recompute from the interval.
